---
ナンパ初心者が自分の力でナンパできるようになるために、必要な知識とスキル、勇気を与えるためのアプリをつくる。

## 価値観・動機

### 望んでいること

* ナンパを「特別なこと」ではなく
  **再現性のあるスキル**として身につけたい
* 失敗してもメンタルが折れない状態になりたい
* 自分で考えて動けるようになりたい
  （誰かのセリフ丸暗記は不安）
* 「今日は一歩前進した」と実感したい

### ナンパへの本音

* モテたいだけではない
* 女性と自然に会話できる自信がほしい
* 人生の選択肢を増やしたい
* 「行動できない自分」から脱却したい

## 行動特性

* インプットはする（動画・記事・SNS）
* しかしアウトプット（実践）が圧倒的に少ない
* 失敗体験を過剰に反芻するタイプ
* 一人で考え込みやすい
* ゲーム感覚・ステップ形式だと行動しやすい

## このペルソナに必要なもの

### 知識

* ナンパは「才能」ではなく「構造」であること
* 断られるのは普通であり、失敗ではないこと
* 女性心理の最低限（警戒・安心・興味）

### スキル

* 声をかけるまでの心理ハードルの下げ方
* 最初の一言の選択肢（複数）
* 会話を続けるための質問・反応テンプレ
* ダメだったときの安全な撤退方法

### 勇気

* 「今日は1人に声をかけた＝成功」という再定義
* 小さな成功体験の積み上げ
* 一人で戦っていないという感覚

## アプリに期待している役割（超重要）

このペルソナにとってアプリは：

* 教官 ❌
* 天才ナンパ師 ❌
* **隣で一緒にやってくれるコーチ ⭕**

### 理想のアプリ像

* 「今日はここまでやればOK」と明確に示してくれる
* 実践前に気持ちを整えてくれる
* 実践後に
  「それでいい」「ちゃんと前進してる」と言ってくれる
* セリフを押し付けず、考え方を教えてくれる
* 恥ずかしさ・怖さを否定しない
